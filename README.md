# 🎫 IT Helpdesk & Ticket Intelligence Dashboard

An interactive **Power BI dashboard** designed to analyze IT helpdesk tickets, monitor SLA performance, track resolution times, and evaluate customer satisfaction. The dashboard provides actionable insights to improve support operations and service efficiency.

## 📌 Project Overview

This project analyzes **5,000+ IT support tickets** to understand ticket volume, resolution performance, SLA compliance, priorities, departments, support channels, and customer satisfaction.

The dashboard helps support teams identify operational bottlenecks and improve overall service performance.

## 📊 Key KPIs

The dashboard tracks important support metrics such as:

* **Total Tickets:** 5,000
* **SLA Breach Percentage**
* **Average Resolution Time**
* **Customer Satisfaction**
* **Open Tickets:** 2,454
* **Resolved Tickets:** 2,546

## 📈 Dashboard Features

### 🎟️ Ticket Overview

Provides a complete overview of total, open, and resolved support tickets.

### ⏱️ SLA Performance Analysis

Tracks SLA breaches and monitors SLA compliance across different months.

### 📅 Monthly Ticket Trends

Analyzes resolved tickets and total tickets over time.

### 🏢 Department-wise Analysis

Shows the number of support tickets generated across departments such as:

* Network
* IT Support
* Software
* Security
* Hardware

### 🔴 Priority Analysis

Analyzes tickets based on priority levels:

* Critical
* High
* Medium
* Low

### 💬 Channel Analysis

Tracks tickets received through multiple support channels:

* Email
* Chat
* Phone
* Portal

### 👨‍💻 Agent Performance

Compares average resolution time across different support agents.

### 😊 Customer Satisfaction Analysis

Monitors customer satisfaction trends to evaluate support quality.

## 💡 Key Insights

* Identifies departments generating the highest number of support tickets.
* Tracks the relationship between total and resolved tickets.
* Highlights SLA breaches that require immediate attention.
* Helps compare agent performance based on resolution time.
* Analyzes ticket distribution across priorities and support channels.
* Monitors customer satisfaction to identify service improvement opportunities.

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Explore the interactive dashboard.
4. Use slicers to filter data by:

   * Priority
   * Channel
   * Department
   * Ticket Status
